# 백성준 포트폴리오

백엔드 개발자 백성준의 포트폴리오 겸 이력서 페이지입니다.

- 주소: https://baekseongjun.github.io
- 구성: 빌드 도구 없는 단일 `index.html` (CSS · 바닐라 JS), Pretendard 폰트
- 넓은 화면에서는 한 장씩 넘기는 덱(→ / Space / 휠), 휴대폰에서는 일반 스크롤로 동작합니다

## 로컬에서 보기

```bash
python -m http.server 8000
# http://localhost:8000
```

## 수정과 배포

`index.html`을 고치고 `main` 브랜치에 push하면 GitHub Pages가 1~2분 안에 자동으로 다시 배포합니다.
